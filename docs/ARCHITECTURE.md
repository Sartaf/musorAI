# Архітектура

## Зараз (v1)
- Ванільний HTML/JS без збірки, обгорнутий у Capacitor (Android).
- Дані: `www/scenarios.json` (6 ситуацій, 29 кроків). Кожен крок: `text`, `ref` (норма), `found` (чи підтверджено джерелами).
- Фраза вголос: Web Speech API (uk-UA). SOS: `sms:` з готовим текстом. Номер зберігається в localStorage.

## Далі
1. **Перевірка змісту.** Пройти кожен сценарій, звірити норми з zakon.rada.gov.ua, виставити `found=true` / `verified=true` і дату перевірки. Зовнішня перевірка юристом.
2. **ШІ-довідник (зроблено).** Go-сервер, `POST /api/ask`. У системний промпт завантажується вся база знань (статті законів, нотатки, сценарії); модель відповідає лише з неї, з посиланням на статтю, а за браком даних каже «у базі цього немає». Ключ API тільки на сервері, ліміт 15 запитів за 10 хвилин на IP, питання до 1000 символів. База кешується (prompt caching), тож повторні запити дешевші.
3. **SOS з геолокацією** (Capacitor-плагін) і відправка відео.
4. **Новi ситуації** за запитами користувачів.

## Правила контенту
- Порада без норми позначається "порада, не норма".
- Сумнівне формулюється обережно і відсилає до юриста.
- Застереження: довідкова інформація, а не індивідуальна консультація.

## Межі ШІ-довідника
- Це не юрист. Якість відповідей дорівнює повноті й точності бази знань.
- Перед публічним запуском: перевірка юристом, політика конфіденційності (питання користувачів проходять через сервер і API Anthropic), юридичне застереження в застосунку.
- Не логувати тексти питань.
