# Тексти законів для бази знань

Сюди завантажуються ПОВНІ офіційні тексти законів. Після кожного завантаження файлу
GitHub сам запускає збірку: потрібні статті копіюються в `knowledge/` слово в слово.

Назви файлів (розширення .txt, .html або .docx):

| Файл | Закон | Офіційна сторінка |
|---|---|---|
| `npu.txt` | Закон «Про Національну поліцію» | https://zakon.rada.gov.ua/laws/show/580-19 |
| `kupap.txt` | КУпАП | https://zakon.rada.gov.ua/laws/show/80731-10 |
| `kpk.txt` | Кримінальний процесуальний кодекс | https://zakon.rada.gov.ua/laws/show/4651-17 |
| `konstytutsiia.txt` | Конституція України | https://zakon.rada.gov.ua/laws/show/254%D0%BA/96-%D0%B2%D1%80 |

Перелік статей редагується в `scripts/kb_articles.json`.
