# Мої права (musorAI)

Швидка підказка для українців: що робити і що казати під час зупинки поліцією, перевірки ТЦК, затримання, обшуку. Кожен крок має посилання на норму закону і позначку, чи її знайдено в джерелах.

Принципи:
- Термінова допомога безкоштовна, без paywall.
- Юридичний текст пишуть і перевіряють люди. ШІ (пізніше) лише підбирає сценарій за описом ситуації.
- Працює офлайн.

## Запуск
```
npm install
npm run serve        # перегляд у браузері
npm run android:add  # один раз: створити Android-проєкт
npm run android:sync # після змін у www/
npm run android:open # відкрити в Android Studio
```

## ШІ-довідник (поле «Запитати»)
Відповідає тільки з бази знань (`knowledge/` + перевірені сценарії), з посиланням на статтю, і чесно каже, коли відповіді в базі немає.
```
python3 scripts/build_kb.py                 # завантажити статті законів у knowledge/
cd server
export ANTHROPIC_API_KEY=sk-ant-...
go run .                                    # слухає :8080
```
Потім у `www/config.js` вкажіть адресу сервера (`window.API_URL`). Ключ API лежить лише на сервері, не в застосунку.

## Структура
- `www/index.html`: застосунок (без збірки)
- `www/scenarios.json`: всі ситуації, кроки, норми, фрази
- `docs/scenario.schema.json`: формат сценарію
- `knowledge/`: тексти статей для ШІ (нотатки + вивантаження зі скрипта)
- `server/`: Go-сервер ШІ-довідника
- `scripts/`: вивантаження статей законів
- `docs/ARCHITECTURE.md`, `docs/SOURCES.md`: план і джерела
